# 프롬프트 카드 01 — 종이 스케치 → 캐릭터 JSON

## 1) 종이에 그릴 때 (5분)

- **옆모습(side view)** 으로 그립니다. 캐릭터가 **오른쪽을 보고 서 있게** (오른쪽 = 앞 = 전진 방향).
- 몸은 **막대(마디, segment)** 몇 개로 단순화합니다. 마디 4~9개, 그중 모터가 붙을 관절 4~8개가 적당합니다.
- 각 마디 옆에 **영문 이름**을 적습니다. 예: `torso`, `head`, `thigh_r`, `shin_r`, `foot_r`, `tail`
- 마디가 이어지는 곳(관절)에 **동그라미**를 그리고, 한쪽으로만 꺾이는 관절(무릎 등)은 화살표로 방향을 표시합니다.
- **바닥에 닿는 마디(발)** 에 ★ 표시. 힘을 주지 않을 관절(머리, 꼬리, 귀)에는 "free" 라고 적습니다.
- 전체 **키(m)** 를 적습니다. 사람 크기(0.5~2 m)가 학습이 잘 됩니다.
- 왼/오 다리는 옆모습에서 겹치므로 하나만 그리고 "x2 (_l, _r)" 라고 적어도 됩니다.

## 2) AI 에게 보낼 프롬프트

사진을 첨부하고 아래를 그대로 붙여 넣습니다. `{ }` 부분만 채우세요.
(형식 예시는 `characters/dog.json` 또는 `characters/biped.json` 파일 내용을 복사해 붙이면 됩니다.)

```
너는 2D 물리 시뮬레이션(MuJoCo) 캐릭터 설계 도우미다. 첨부한 손그림(옆모습)을 보고 아래 형식의 JSON spec 을 만들어라.

[캐릭터 설명] {예: 다리가 짧은 강아지. 키 약 0.9 m. 앞다리/뒷다리 각 2마디, 머리와 꼬리는 힘 없이 흔들림}

[좌표 규칙]
- x 는 오른쪽이 앞(+), z 는 위(+). 단위 m. 전체 높이는 약 {키} m. 발바닥이 z=0 근처에 오도록.
- 옆모습이므로 왼/오 다리는 같은 위치에 겹쳐서 만들고 이름 끝에 _l, _r 를 붙인다.

[segments 규칙]
- 각 마디는 캡슐이며 필드는 name, parent, start [x,z], end [x,z], radius, joint_range, motor, friction, color.
- 정확히 하나의 마디만 "parent": null (몸통, name 은 "torso"). 나머지는 parent 에 붙는 마디 이름을 쓴다.
- start 는 부모 마디와 연결되는 관절 위치이며 부모 마디 위(또는 끝)의 점이어야 한다. end 는 그 마디의 끝점.
- radius(두께)는 0.03~0.12. 몸통은 두껍게, 다리는 가늘게.
- joint_range 는 [최소, 최대] 도(deg). 자유롭게 움직이는 관절은 [-60, 60] 정도, 무릎처럼 한쪽으로만 꺾이는 관절은 [-150, 0] 또는 [0, 150].
- 바닥에 닿는 마디(발)에는 "friction": 1.9 를 넣는다.
- 힘을 주지 않는 관절(머리, 꼬리, 귀 등)은 "motor": false. 모터가 있는 관절은 4~8개.
- name 은 영문 소문자, 숫자, 밑줄만. color 는 "brown","purple","blue","red","green","gray","yellow","white" 중 선택.

[출력 규칙]
- JSON 만 출력하고 설명은 쓰지 않는다. 마지막 항목 뒤에 쉼표를 남기지 않는다.

[형식 예시]
{여기에 characters/dog.json 내용을 붙여 넣기}
```

## 3) 받은 JSON 저장하고 실행

1. 받은 JSON 전체를 복사해 `characters/my_character.json` 에 붙여 넣고 저장 (메모장에서 열어도 됩니다. 인코딩은 UTF-8).
2. 터미널에서:
   ```
   python 2_build_character.py
   python 3_play.py my_character
   ```
3. `[실패]` 나 `[경고]` 가 나오면 그 메시지와 JSON 을 AI 에게 함께 주고 이렇게 말합니다.
   ```
   위 JSON 을 실행했더니 아래 오류가 났다. 규칙에 맞게 고친 전체 JSON 을 출력해라.
   {오류 메시지 붙이기}
   ```

## 4) 잘 되는 캐릭터의 조건

- 발이 몸통 아래에 있어서 힘을 안 줘도 잠깐은 서 있을 수 있다 (`--mode zero` 로 확인).
- 다리 마디가 2~3개, 무릎 방향이 정해져 있다 (`joint_range` 가 한쪽으로 치우침).
- 너무 무거운 머리/꼬리가 없다 (radius 를 작게).
- 마디 8개 이하, 모터 4~8개.

## 5) 수정하고 싶을 때 자주 쓰는 말

- "다리를 20% 더 길게 해 줘" / "무릎이 반대로 꺾이게 해 줘" / "꼬리를 없애 줘"
- "몸통을 더 두껍게(radius 0.12) 해 줘" / "발을 더 길게 해서 잘 서 있게 해 줘"
- "관절 범위를 절반으로 줄여 줘"
